# Задание:
Написать программу, которая:

1. Реализует функцию factorial(n int) int, которая возвращает факториал числа n.
    * Факториал n! = 1 * 2 * 3 * ... * n.
    * Для 0! - результат равен 1.
    * Например: 5! = 120.
2. Реализует функцию max(arr []int) int, которая возвращает максимальное число в срезе.
    * Например: [1, 7, 3, 9, 2] → 9.
3. В main() протестировать обе функции:
    * Вводить число с консоли и выводить его факториал.
    * Создать массив из 5–6 чисел и вывести максимальное.
