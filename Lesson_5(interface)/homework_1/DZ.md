Студенты и фильтрация по среднему баллу
Задача:
Разработать программу для хранения данных о студентах.
   У каждого студента есть:
        фамилия;
        имя;
        возраст;
        курс;
        средний балл.
   Программа должна уметь:
        хранить данные в структуре Student;
        использовать срез для списка студентов;
        добавлять нового студента;
        фильтровать студентов по минимальному среднему баллу;
        выводить студентов в формате: Фамилия Имя, курс, возраст, средний балл;
        использовать интерфейс с методом Display().
