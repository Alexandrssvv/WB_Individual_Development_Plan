Товары на складе
Задача:
Написать программу для работы с товарами.
    У каждого товара есть:
        название;
        категория;
        цена;
        количество на складе.
    Программа должна:
        хранить товары в структуре Product;
        добавлять новый товар;
        фильтровать товары по минимальной цене;
        фильтровать товары по минимальному остатку;
        выводить список товаров;
        использовать интерфейс для вывода информации.
