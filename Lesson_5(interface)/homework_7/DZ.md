Заказы интернет-магазина
   Задача:
   Создать программу для работы с заказами.
   У заказа есть:
       номер заказа;
       имя клиента;
       сумма заказа;
       статус;
       количество товаров.
   Программа должна:
       хранить заказы в структуре Order;
       добавлять новый заказ;
       фильтровать заказы по минимальной сумме;
       фильтровать заказы по статусу;
       выводить заказы в удобном формате;
       использовать интерфейс для отображения.
