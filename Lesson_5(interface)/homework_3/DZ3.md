Автомобили и фильтрация по году выпуска
   Задача:
   Создать программу для хранения информации об автомобилях.
       Поля:
       марка;
       модель;
       год выпуска;
       пробег;
       цена.
   Программа должна:
       хранить автомобили в срезе;
       добавлять новый автомобиль;
       выводить только автомобили новее заданного года;
       выводить только автомобили с пробегом меньше заданного;
       использовать интерфейс Printable с методом Print().
