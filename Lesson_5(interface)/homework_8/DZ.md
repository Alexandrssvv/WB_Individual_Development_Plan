Курсы онлайн-школы
   Задача:
   Разработать программу для хранения информации о курсах.
   У курса есть:
       название;
       преподаватель;
       длительность в часах;
       цена;
       количество учеников.
   Программа должна:
       хранить список курсов;
       добавлять новый курс;
       фильтровать курсы по минимальной цене;
       фильтровать по минимальной длительности;
       выводить список;
       использовать интерфейс Displayable.
